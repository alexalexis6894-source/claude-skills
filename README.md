# Набор скиллов и рабочих правил для Claude Code и Codex

34 скилла и общие правила работы агента: анализ ниши TikTok с картой тем, русская редактура,
нейминг, разбор бизнеса, планирование тремя агентами, наглядные статьи, LinkedIn и другое.
Личных данных, клиентских материалов и ключей здесь нет: каждый подключает свои доступы.

## Установка одной фразой

Откройте Claude Code (терминал, приложение или claude.ai/code) и вставьте:

```text
Установи мне набор скиллов и рабочих правил из https://github.com/alexalexis6894-source/claude-skills.
Склонируй репозиторий во временную папку, прочитай README.md, CLAUDE.md и install.sh,
затем запусти `bash install.sh`. Мой CLAUDE.md не заменяй: если установщик напишет NEEDS_MERGE,
выполни скилл rules-merge, допиши в мой CLAUDE.md только то, чего в нём ещё нет и что
не спорит с моими правилами, и обязательно проверь результат отдельным субагентом
на повторы, противоречия и пропуски. После установки покажи, что добавлено, что пропущено
как уже имеющееся, кратко объясни, что умеет каждый скилл, и спроси, какую задачу
я хочу решить первой. Если для анализа TikTok нужен APIFY_TOKEN, дай прямую ссылку,
где его взять, и куда его положить. Если ты работаешь в облачной сессии claude.ai/code,
установка в ~/.claude пропадёт после сессии: тогда скажи мне нажать Fork на странице
репозитория и открыть новую сессию на моей копии, там скиллы и правила подхватятся сами.
```

Обновление: та же фраза ещё раз. Скиллы заменятся на свежие, блок правил набора пересоберётся,
ваш собственный текст в CLAUDE.md останется как был.

## Вариант для облака (claude.ai/code)

Облачная сессия каждый раз стартует в чистом контейнере, поэтому установка в `~/.claude`
там не сохраняется. Вместо неё:

1. Нажмите **Fork → Create fork** вверху этой страницы. Получится ваша копия.
2. Откройте https://claude.ai/code и выберите свою копию как репозиторий сессии.
   Скиллы из `.claude/skills/` и правила из `CLAUDE.md` подхватятся сами, при старте
   облачной сессии хук ещё и поставит gstack (55 инженерных скиллов Гарри Тана).
3. Работайте прямо в этом репозитории: результаты (страницы, исследования) кладите в `site/`
   и `research/`.

## Анализ TikTok: что понадобится

- Аккаунт Apify и токен: https://console.apify.com/settings/integrations → **Personal API tokens**
  → скопировать. Положить в переменную окружения `APIFY_TOKEN` (в терминале `export APIFY_TOKEN=...`,
  в облаке claude.ai/code: название среды → Edit → Environment variables). В чат токен не присылать.
- Бесплатного кредита Apify ($5 в месяц) хватает примерно на два-три анализа ниши:
  типичный сбор стоит $1,5–2, потолок задаётся в каждом запуске.
- Результат: страница `site/<slug>/index.html` с таблицей всех тем ниши. Открыть локально
  (`python3 -m http.server` в папке `site`) или выложить на GitHub Pages / Netlify Drop.

## Правила работы (CLAUDE.md): дополнение, а не замена

- **Своего CLAUDE.md нет:** правила набора ставятся целиком.
- **Свой CLAUDE.md есть:** установщик его не трогает. Скилл `rules-merge` сверяет каждое правило
  набора с вашими по смыслу и дописывает отдельным блоком только новое. То, что у вас уже сказано
  (хоть другими словами), не повторяется. Где ваше правило говорит иначе, остаётся ваше.
  Затем отдельный субагент вслепую проверяет блок на повторы, противоречия и пропуски
  и сверяет, что ваш текст не изменён. Копия прежнего файла лежит рядом в `.bak`.
- **Ваш скилл с тем же именем**, что в наборе, не теряется: он переносится в `~/.claude/skills-backup-<дата>/`.

Что в правилах: агент сам доводит задачу до проверенного результата, проверяет интерфейсы
в браузере со скриншотами, при блокере даёт готовое решение со ссылкой, большие задачи ведёт
через `skill-scout` и параллельных субагентов, отчёты делает веб-страницами, пишет по-русски
без канцелярита. Блок набора стоит между маркерами `skills-kit:begin/end`.
