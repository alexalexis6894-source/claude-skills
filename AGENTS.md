# AGENTS.md

Правила для Codex и других агентов совпадают с правилами Claude Code: прочитай `CLAUDE.md`
в корне репозитория и следуй им. Скиллы лежат в `.claude/skills/` (для Codex доступны
через ссылку `.agents/skills`). Названия моделей в скиллах привязаны к Claude Code: если
Sonnet недоступен, выбери доступную сильную модель и отметь замену.
